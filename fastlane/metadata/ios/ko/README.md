# App Store 한국어 메타데이터

Fastlane `deliver`의 `metadata_path`를 `fastlane/metadata/ios`로 지정할 때 쓰는
한국어(`ko`) 디렉터리다. MAR-34에서 Marco가 문구와 URL을 확정한 뒤 아래 파일을
추가한다.

- `name.txt`
- `subtitle.txt`
- `description.txt`
- `keywords.txt`
- `promotional_text.txt`
- `privacy_url.txt`
- `support_url.txt`

이 디렉터리에 계정, 심사 연락처, 비밀번호 또는 API 키를 커밋하지 않는다.
