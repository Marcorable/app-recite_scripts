# 스토어 심사 노트

> MAR-36 초안. 제3자 텍스트, 계정 정보, 개인정보를 넣지 않는다.

## iOS App Review Notes 초안

아래 본문은 최종 release 빌드에서 재현한 뒤 App Store Connect의 Notes에 복사한다.

```text
말또는 사용자가 직접 입력한 대본을 소리 내어 읽을 때 현재 위치를 표시하고 반복 낭독을 돕는 앱입니다.

로그인, 계정 생성, 광고, 제3자 앱·웹사이트를 가로지르는 추적, 인앱 구매는 없습니다. 앱에는 기본 대본이나 제3자 콘텐츠가 포함되어 있지 않습니다. 테스트할 내용은 심사자가 직접 입력할 수 있습니다.

재현 순서
1. 첫 화면 오른쪽 위의 “추가”를 누릅니다.
2. 제목에 “테스트”, 본문에 “오늘도 차분하게 한 문장씩 읽습니다”를 입력하고 “저장”을 누릅니다.
3. 목록에서 방금 만든 대본을 누릅니다.
4. 대본을 선택할 때 처음 표시되는 마이크와 음성 인식 권한을 허용합니다. 앱은 필요한 한국어 온디바이스 음성 인식 asset 설치를 자동으로 요청합니다.
5. 준비가 끝나 낭독 설정이 열리면 횟수를 1회로 두고 “낭독 시작”을 누릅니다. 설정 화면에 “준비 상태 확인”이 표시되면 asset 설치가 끝난 뒤 그 버튼을 누릅니다. 설정 화면이 열리기 전에 준비 중 안내가 표시되면 안내를 닫고 설치 완료 후 목록에서 대본을 다시 선택합니다.
6. 입력한 문장을 한국어로 읽으면 인식 결과에 따라 어절 하이라이트가 앞으로 이동하고, 끝까지 읽으면 완료 화면이 표시됩니다.

마이크는 낭독 세션 중에만 사용합니다. iOS SpeechAnalyzer와 SpeechTranscriber로 한국어 음성을 기기에서 처리합니다. 앱은 오디오 파일을 만들거나 음성을 저장하지 않으며, 사용자가 입력한 대본은 앱의 로컬 저장소에만 보관합니다. 낭독 화면에서 나가거나 앱이 백그라운드로 전환되면 음성 인식과 오디오 세션을 종료합니다.

외부 서비스는 Firebase Analytics, Crashlytics, App Check만 사용합니다. 사용 통계·오류 진단과 앱 무결성 확인을 위한 것이며, 앱 코드의 전송 항목에 사용자가 입력한 대본이나 음성은 포함하지 않습니다. 상세 데이터 처리는 App Privacy와 공개 개인정보처리방침에 기재합니다.

로그인이 필요하지 않으므로 데모 계정은 없습니다.
```

## 범위와 의존성

- MAR-34: 앱 이름을 제외한 App Store 문구, Support URL, Marketing URL 여부를 소유한다.
- MAR-35: Privacy Policy URL, Firebase/제3자 SDK 감사, App Privacy 답변을 소유한다.
- MAR-52: 제출용 스크린샷과 생성·검증 자동화를 소유하며 PR #95로 `develop`에 병합됐다. MAR-36은 최종 release UI와 일치 여부만 다시 확인한다.
- MAR-55: App Store Guideline 2.1 추가 정보, 실제 기기 영상, 공개 링크, Notes 업데이트와 재제출을 소유한다. MAR-36은 상태와 의존성만 기록한다.
- MAR-36: 위 산출물을 중복 작성하지 않고, 최종 빌드와 심사 정보가 서로 일치하는지 연결·검증한다.

## Google Play 검토용 재현 안내 초안

Google Play에는 App Store의 자유 형식 Notes와 동일한 필드가 항상 보장되지 않는다. App access 또는 검토 중 추가 정보 입력란이 실제로 표시될 때만 아래 내용을 사용한다.

```text
말또는 사용자가 직접 입력한 대본을 소리 내어 읽을 때 현재 위치를 표시하고 반복 낭독을 돕는 앱입니다.

로그인, 계정 생성, 광고, 인앱 구매는 없습니다. 앱에는 기본 대본이나 제3자 콘텐츠가 포함되어 있지 않습니다.

재현 순서
1. 첫 화면 오른쪽 위의 “추가”를 누릅니다.
2. 제목에 “테스트”, 본문에 “오늘도 차분하게 한 문장씩 읽습니다”를 입력하고 “저장”을 누릅니다.
3. 목록에서 방금 만든 대본을 누릅니다.
4. 처음 표시되는 마이크 권한을 허용합니다.
5. 준비가 끝나 낭독 설정이 열리면 횟수를 1회로 두고 “낭독 시작”을 누릅니다.
6. 입력한 문장을 한국어로 읽으면 인식 결과에 따라 어절 하이라이트가 앞으로 이동하고, 끝까지 읽으면 완료 화면이 표시됩니다.

마이크는 낭독 세션 중에만 사용합니다. Android의 온디바이스 SpeechRecognizer를 ko-KR로 사용합니다. 앱은 오디오 파일을 만들거나 음성을 저장하지 않으며, 사용자가 입력한 대본은 기기의 로컬 저장소에만 보관합니다. 낭독 화면에서 나가거나 앱이 백그라운드로 전환되면 음성 인식을 종료합니다.

로그인이나 제한된 기능이 없으므로 검토용 계정은 필요하지 않습니다.
```

Firebase Analytics, Crashlytics, App Check의 데이터 처리는 음성·대본 처리와 별개다. MAR-35가 확정한 Privacy Policy와 Data Safety 답변을 그대로 사용하고, 이 Notes에서 “앱이 어떤 데이터도 수집하지 않는다”고 표현하지 않는다.
