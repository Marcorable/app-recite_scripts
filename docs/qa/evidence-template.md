# QA 증거 기록 템플릿

| 필드 | 값 |
|---|---|
| 빌드 | `<branch> / <commit SHA> / Debug·Profile·Internal` |
| 환경 | `<기기> / <OS> / <앱 버전> / <네트워크>` |
| 케이스 | `<PRIV-01·STAB-01 등>` |
| 실행 시각 | `<ISO 8601>` |
| 결과 | `통과 / 실패 / 차단 / 해당 없음` |
| 정제된 증거 | `<민감 정보 없는 파일 또는 대시보드 위치>` |
| 판정 | `<본문·전사·음성 포함 여부, 종료 사유 등 상태 정보만>` |
| 후속 | `<없음 또는 Issue URL>` |

사용자 대본·실제 전사문·음성, 요청 토큰, 설치 ID, 로컬 사용자 경로는 기록하지 않는다.
