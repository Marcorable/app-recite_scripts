# MAR-36 스토어 제출 상태 기록

## 2026-11-16 확인 결과

### App Store

- 최신 App Store Connect 심사 상태는 **검증하지 못했다**.
- 기존 Linear 기록상 MAR-55에 2026-11-13 `Guideline 2.1 — Information Needed` 요청이 남아 있다.
- 요청 내용은 실제 기기 최신 OS의 전체 흐름 영상과 앱 목적·사용자·설정·외부 서비스·지역 차이·권리/규제 설명이다.
- 완료로 기록된 사실: 로그인·계정, 결제·구독·인앱 구매, 사용자 콘텐츠 공유 기능이 없고 음성은 Apple 온디바이스 인식으로 처리한다는 설명 준비.
- MAR-55의 남은 항목: 실제 iPhone 영상, 로그인 없는 공개 링크, App Review Notes 업데이트, 같은 빌드 재제출, 결과 기록. MAR-36은 이를 수행하지 않고 상태만 연결한다.
- 2026-11-16 App Store Connect를 다시 열었지만 Apple 계정 로그인 화면이 표시되어 `Waiting for Review`, `In Review`, `Rejected` 등 현재 상태를 판정할 수 없었다.
- 이 확인 과정에서 App Store Connect에 저장·응답·재제출을 하지 않았다.

### Google Play

- 비공개 테스트 `Alpha`의 `0.1.0` release가 선택된 테스터에게 제공 중이며 Console은 2026-11-11 게시로 표시했다.
- 12명이 참여 중이지만 연속 14일 중 4일만 경과해 프로덕션 접근 신청이 비활성이다.
- Publishing 상태는 검토 전송 전이고 프로덕션은 비활성이다.
- 이름 없는 초안 release가 하나 있다. 생성 목적을 확인하기 전 수정하거나 폐기하지 않는다.
- 실제 제출, 프로덕션 접근 신청, release 변경은 수행하지 않았다.

3. 재현 가능한 제품·메타데이터 근거
